품목별 유효 입찰공고

수집 설정 — 품목 · 기간 · 업무구분
K-apt — 전국 의무관리대상 아파트의 입찰공고입니다. 커뮤니티센터·경로당 세탁기 교체, 무인세탁실 설치·위탁운영자 선정, 빨래방 임대 같은 민간 물량이 여기 모입니다.
세탁 전용 판정을 켜면 아래 규칙으로 자동 분류합니다 — 단순 제외어로는 구분이 안 되기 때문입니다.
  · 장비명(세탁기·건조기·무인세탁·코인세탁·빨래방)이 있으면 '공사'가 붙어도 포함 (예: "세탁실 무인세탁기 설치 공사" → 포함)
  · 장비명 없이 세탁실 + 방수·누수·배관·타일·도장·철거만 있으면 제외 (예: "세탁실 누수 방수공사" → 제외)
  · 품목표의 제외 키워드는 두 경우 모두 최종 적용됩니다.
검색 + 목록(권장) — 두 방식을 모두 돌려 합칩니다.
나라장터 검색(PPSSrch) — 조달청 서버가 공고명을 직접 검색합니다. 응답이 작아 빠르고 호출 수도 적습니다. (실측: 15일치 "세탁기" 검색 = 2건 수신)
전체 목록 — 기간 내 공고를 전량 받아 앱이 직접 거릅니다. 공고명뿐 아니라 세부품명·공고번호까지 매칭되지만 응답이 큽니다 (실측: 15일치 물품만 6,155건).
※ 조달청 실측 결과 /ad/ 경로 · 기준일 inqryDiv=1 조합만 유효하여 그 조합만 호출합니다.
품목명 포함 키워드 (쉼표 구분) 제외 키워드 세부품명번호 앞자리
포함 키워드 또는 품명번호 앞자리가 맞으면 매칭됩니다(OR). 제외 키워드는 그보다 우선합니다.
설정은 이 브라우저에만 저장됩니다. 다른 PC에서 쓰려면 설정 내보내기/불러오기를 사용하세요.
진단 실행 — 조달청 응답 원문 확인
앱의 필터를 거치지 않고 조달청이 실제로 보낸 원문을 검사합니다. 상태 표시의 뜻은 다음과 같습니다.
정상 — 오퍼레이션이 살아있고 응답을 받았습니다. 상위 N건만 검사 가 붙으면 기간 총건수가 커서 앞쪽 일부만 훑은 것이며, 키워드가 뒤쪽 페이지에 있으면 키워드 일치 0 으로 보일 수 있습니다. 키워드 판정은 검색(PPSSrch) 행을 우선 보십시오.
미제공/미승인 — 조달청에 그 오퍼레이션이 없거나 활용신청에 포함되지 않았습니다. 정상 상황입니다.
건너뜀 — 진단 전체 시간 예산(50초)을 초과해 호출하지 못했습니다. 조회 기간을 줄이면 해소됩니다.
K-apt 엔드포인트 탐지 — 공동주택(K-apt) 입찰공고 API는 서비스명·날짜 파라미터 표기가 공개 문서마다 달라, 후보를 차례로 호출해 실제로 응답하는 조합을 찾아냅니다. 결과가 모두 미승인 이면 공공데이터포털에서 K-apt 입찰공고 활용신청 을 먼저 하십시오(인증키는 기존 것을 그대로 씁니다).
품목 설정과 무관하게 입력한 키워드로 바로 마감 전 공고를 찾습니다. 공고명·세부품명·공고번호 어디든 포함되면 잡히며, 짧게 넣을수록 넓게 잡힙니다 (세탁기는 "세탁물 처리 용역"을 놓치지만 세탁은 둘 다 잡습니다).
설정을 확인한 뒤 공고 수집을 누르세요.
