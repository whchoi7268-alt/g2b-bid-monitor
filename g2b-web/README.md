# 품목별 유효 입찰공고 모니터

조달청 나라장터 + K-apt(공동주택) 입찰공고를 품목 키워드로 모아
**입찰마감이 아직 지나지 않은 공고만** 한 화면에 보여주는 사내 전용 웹앱.

운영 URL: https://g2b-bid-monitor-chi.vercel.app

---

## 1. 무엇을 하는가

| 단계 | 처리 |
|---|---|
| ① 수집 | 최근 N일 공고를 기간 구간으로 나눠 병렬 조회 |
| ② 필터 | `입찰마감일시 > 조회시각` 인 건만 남김 |
| ③ 매칭 | 품목 키워드 **또는** 세부품명번호 앞자리 (제외 키워드 우선) |
| ④ 표시 | D-Day·마감임박 배지, 정렬·검색, 엑셀/CSV 내보내기 |

---

## 2. 구조

```
index.html      화면 (설정·수집·진단·결과 표)
api/_lib.js     공용 — 인증, 나라장터 호출, 정규화·필터
api/_kapt.js    K-apt 어댑터 — 엔드포인트 자동탐지, 세탁 판정
api/auth.js     비밀번호 로그인
api/status.js   설정 상태 · 인증키 자가진단 · K-apt 엔드포인트 탐지
api/bids.js     수집 (source=g2b | kapt)
api/diag.js     진단 — 조달청 응답 원문 확인
api/export.js   엑셀(xlsx) / CSV 내보내기
api/mcp.js      MCP 서버 (Claude 커스텀 커넥터)
build.mjs       배포 산출물 dist/ 생성
```

## 3. 환경변수 (Vercel → Settings → Environment Variables)

| 변수 | 필수 | 설명 |
|---|---|---|
| `APP_PASSWORD` | ✅ | 페이지 접속 비밀번호 |
| `G2B_SERVICE_KEY` | ✅ | 조달청 나라장터 인증키 |
| `MCP_TOKEN` | | MCP 서버 접속 토큰. 없으면 MCP 비활성 |
| `KAPT_SERVICE_KEY` | | K-apt 전용 인증키. 없으면 `G2B_SERVICE_KEY` 재사용 |
| `KAPT_ENDPOINT` | | K-apt 경로 교정 (예: `AptBidInfoService/getAptBidInfo`) |
| `KAPT_DATE_BEGIN` / `KAPT_DATE_END` | | K-apt 날짜 파라미터명 교정 |

> 환경변수 변경은 **새 배포에만** 반영됩니다. 값 등록 후 Deployments → 최신 배포 `⋯` → **Redeploy**.

## 4. 실측으로 확정된 API 사실

조달청 나라장터 (기관코드 1230000)

- 유효 조합은 **`/ad/` 경로 + `inqryDiv=1`** 뿐. `/1230000/BidPublicInfoService`(‑ad)는 `NO_OPENAPI_SERVICE_ERROR`, `inqryDiv=2`는 `[08] 필수값 입력 에러`.
- `...PPSSrch` 오퍼레이션은 **공고명을 서버가 직접 검색**한다. 기본 목록 오퍼레이션은 `bidNtceNm` 을 **에러 없이 무시**하므로 클라이언트 필터가 필요하다.
- 인증키는 Encoding/Decoding 두 형태가 있고, `URLSearchParams` 로 넣으면 재인코딩되어 깨진다 → **직접 이어붙이고 통한 형태를 기억**한다.
- 인증키 오류가 **JSON 200**으로 오는 경우가 있어, `response` 키가 없으면 반드시 throw 한다 (조용한 0건 금지).

K-apt 공동주택 (기관코드 1611000)

- 같은 계열 실제 경로: `AptBasisInfoService/getAphusBassInfo`, `AptListService/getLegaldongAptList`
- **입찰공고 서비스명은 미확정.** 후보 30개 전부 `NO_OPENAPI_SERVICE_ERROR` → 경로 문제 (인증키는 정상).
- 확정 방법: 공공데이터포털 → 마이페이지 → 개발계정 → **공동주택 입찰공고 정보제공 서비스(15058166)** → 활용신청 상세기능정보 → **`확인`** → 요청 URL 확인 → `KAPT_ENDPOINT` 에 `1611000/` 뒤쪽만 등록.

오류 문구로 원인을 구분하는 규칙

| 응답 | 의미 |
|---|---|
| `NO_OPENAPI_SERVICE_ERROR` | 그 주소에 서비스 없음 (경로 문제) |
| `SERVICE_KEY_IS_NOT_REGISTERED` | 주소는 있으나 활용신청 미승인 |
| `[08] 필수값 입력 에러` | 주소·키 정상, 파라미터만 불일치 |
| `resultCode 00` | 정상 |

## 5. K-apt 세탁 판정 규칙

단순 제외어로는 *"세탁실 무인세탁기 설치 공사"* 가 통째로 빠지므로 별도 분류기를 둔다.

| 조건 | 판정 |
|---|---|
| 장비명(세탁기·건조기·무인세탁·코인세탁·빨래방·린넨) 포함 | **포함** — '공사'가 붙어도 |
| 장비명 없이 세탁실 + 보수성 단어(방수·누수·배관·타일·도장·철거) | **제외** |
| 세탁실 + 구축성 단어(설치·구축·신설·임대·위탁·운영) | **포함** |
| 세탁 관련어 없음 | 제외 |

품목표의 **제외 키워드**는 어느 경우에도 최종 적용된다. 검증: 10/10 통과.

## 6. 배포

Git 연결 시 `main` push → 자동 배포.

수동 배포(전체 스냅샷)일 때는 반드시 아래로 산출물을 만들어 **전 파일을 한 번에** 올린다.

```bash
node build.mjs   # dist/ 생성 — api 최소화 + index.html 스크립트 분리
```

> ⚠️ 수동 배포는 **전체 파일 스냅샷**이다. 빠진 파일은 운영에서 삭제된다.
> 실제로 이 프로젝트에서 화면·라우트 삭제 사고가 여러 차례 발생했다. **Git 연결을 권장한다.**

---

## 7. 운영 유의사항

- 본 화면은 **수집 시점 스냅샷**이며 실시간이 아니다. 투찰 전 원문 공고 확인 필수.
- 개발계정 기본 트래픽은 1,000건/일. 조회기간을 늘리면 호출이 급증한다.
- 설정은 브라우저 localStorage 에만 저장된다. 다른 PC에서 쓰려면 **설정 내보내기/불러오기** 사용.
